The reverse lobe, edge weighting, exposure and persistent contour remain explicitly artistic adaptations. It is not a complete energy-conserving glass BSDF, caustic solver or internal-reflection simulation. Blend zero preserves the candidate-13 rendering path. User parameters and the full previous output were backed up in `evidence/material-facing13-20260922T141842489Z/`.

Candidate 15 (2026-09-22) responds to the user's photographs of candidate 14's axial bright bands and centre washout. Original probe code now defines a two-axis aspheric heightfield above a planar back. A reciprocal local path refracts through the top, reflects from the plane and exits through the same local tangent; exact unpolarized dielectric Fresnel includes entry/exit transmission losses and rejects unavailable single-bounce exits. It is not a spatial ray tracer or a complete lens BSDF; background refraction remains the prior bounded displacement. Source area scaling, a fixed UI exposure convention and conservative interface budgets replace the old 8x gain and mirrored convex lobe in this branch. They are explicit UI approximations, not proof of energy conservation. The old branch is retained behind `planoLens=false`. Mathematical references: [PBRT specular reflection/transmission](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission); geometry terminology: [Edmund Optics lens geometries](https://www.edmundoptics.com/knowledge-center/application-notes/optics/understanding-optical-lens-geometries/). No new source/assets/dependencies were imported. Prior output, shader, parameters and unmodified user photographs are preserved in `evidence/material-distance14-20260922T144310287Z/`. Numerical tests do not count as visual acceptance.
